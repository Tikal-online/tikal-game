# TikalComponents

Angular workspace for `tikal-ui-components`, the shared UI component library of the Tikal board game frontend.

## Development server

The component library is run using Aspire. It is not recommended to try to run the project by itself.

## Running unit tests

To execute unit tests with the [Vitest](https://vitest.dev/) test runner, use the following command:

```bash
npm run test
```

to have the runner watch for file changes and rerun affected tests.

```bash
npm run test-ci
```

to run all tests once and exit.
